# mogoo-codex-title 管理技能

本技能随完整插件安装，用于预览和管理话题标题、查看用量、切换官方与中转站模型，以及配置可选的闲置归档。自动命名由插件的后台 Hook 执行。

## 使用

安装后可以说“预览这个话题的新标题”“暂停自动命名”“查看命名用量”或“打开设置页面，切换到中转站”。本地设置页支持编辑模型配置，Windows 可通过「设置密钥」对话框保存密钥环境变量。安装入口和完整功能说明见[插件 README](../../README.md)，操作流程见 [SKILL.md](SKILL.md)。请安装完整插件，单独复制此技能目录不会包含后台程序。

切换已保存的模式，直接说“把标题插件切到中转站”或“把标题插件切回官方账号”；查询时说“看看标题插件现在用哪种模式”。Codex 会复用已保存的配置并反馈结果，下一次命名调用生效。首次配置和图形化入口见 [发一句话切换](../../README.md#发一句话切换)。

## 兼容性与依赖

需要 Python 3.10+、兼容的本地 Codex CLI 和宿主工具。默认官方模式复用 Codex 登录，中转站模型通过环境变量认证。Windows、macOS 与 Linux 的程序测试已通过，各宿主的桌面完整流程需分别验收。云端不支持后台入口。

## 数据与权限边界

命名读取近期对话，默认使用官方账号模型额度；显式启用中转站后，摘录传给所配置的中转站。只改标题元数据，不往原话题添加消息。插件配置只保存密钥环境变量名，密钥对话框写入当前用户环境变量，保存后需要完全重启 Codex。归档默认关闭，需用户认可后启用；已归档话题不重新评估。用量账本不保存对话原文。
